**ChatBubble** — one message in the chat thread. The typeface signals the speaker: `agent` renders in the Source Serif 4 voice (AI-authored text), `user` in Inter sans right-aligned, `system` as a centred muted caption.

```jsx
<ChatBubble author="agent">The most likely cause is a worn seal on line 3.</ChatBubble>
<ChatBubble author="user" name="You">The gasket was replaced last week.</ChatBubble>
<ChatBubble author="system">Switched to Deep mode</ChatBubble>
```
